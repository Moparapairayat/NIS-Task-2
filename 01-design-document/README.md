# Report

This folder holds the final Task 2 report as a PDF, exported from Microsoft Word so that it opens directly in GitHub.

## Report structure

| Part | Assessment criterion | Sections | Main content |
|---|---|---|---|
| a. Network Design | AC 3.1 | 2–13 | Requirements, topology, VLAN and IP plan, cabling, routing, services, security policy and verification plan (Figures 1–3, Tables 1–9) |
| b. Network Installation | AC 3.2 | 14–19 | Placement and cabling, basic configuration, VLANs and trunks, routing, NAT and firewall, installation verification (Figures 4–13, Table 10) |
| c. Network Services and Applications | AC 3.3 | 20–26 | DHCP and relay, DNS, web, FTP and printing, inter-VLAN ACLs, secure management and switch security, service testing (Figures 14–27, Tables 11–13) |
| References | – | – | Harvard-style references |
| Appendix C | – | – | Tools and technologies |
| Appendix D | AC 3.2 | – | Installation evidence (Figures D1–D20) |
| Appendix E | AC 3.3 | – | Service evidence (Figures E1–E8) |

Each part ends with a **Live Evidence** table linking to the Packet Tracer file, scripts and screenshots for that part in this repository.

## Exporting the PDF

In Word: *File › Save As › PDF*. Name the file `NIS_Task2_Report.pdf` and place it in this folder.
